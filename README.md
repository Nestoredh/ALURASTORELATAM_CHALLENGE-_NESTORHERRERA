# ALURASTORELATAM_CHALLENGE-_NESTORHERRERA
CHALLENGE PRACTICANDO PYTHON PARA DATA SCIENCE ALURA STORE
Este proyecto tiene como objetivo analizar los datos de ventas de varias tiendas para recomendar la tienda más rentable , Se evaluaron factores como ingresos totales, categorías de productos más y menos vendidas, calificaciones promedio de los clientes, productos más y menos vendidos y costos de envío.
